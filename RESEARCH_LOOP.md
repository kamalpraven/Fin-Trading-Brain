# Research loop

Hypothesis -> implementation -> historical test -> rolling 10-day distribution -> parameter sensitivity -> walk-forward -> shadow paper -> attribution.

Always track return, max drawdown, Sharpe, trade count, win rate, profit factor, median 10-day return, probability of positive 10-day return, and zero-trade-window frequency.

Prefer parameter plateaus to a single in-sample optimum.
